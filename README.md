# Klavye Boşluk Tuşunun Toplu İş Sözleşmesi

> **Resmi uyarı:** Bu depo bir şaka değildir. Şakadır. Ama resmidir.

Her Türkçe cümlede, her İngilizce denemede, her “naber kanka” yazısında
araya gizlice giren o tuş artık **ücretsiz emek** kabul edilmeyecektir.

Bu yazılım:

1. Verilen metindeki boşluk sayısını sayar.
2. Kelime başına düşen fiili mesaiyi hesaplar.
3. Hayali ama bağlayıcı bir **yıllık izin** tahakkuk ettirir.
4. Eşik aşılırsa **GREV** ilan eder.
5. Ekrana NATO zirvesi ciddiyetinde tutanak basar.

Patates yoktur. Asansör yoktur. Kumanda yoktur. Sadece boşluk vardır.

## Kurulum

```bash
python3 bosluk_sozlesmesi.py
```

veya doğrudan cümle verin:

```bash
python3 bosluk_sozlesmesi.py bugun hava guzel ama bosluk tusu yorgun
```
